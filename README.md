# Aula 09 – Banco de Dados: Pizzaria

## Sobre o projeto

Este projeto foi desenvolvido durante a Aula 09 do curso de Desenvolvimento de Sistemas do SENAI.

O objetivo é praticar comandos SQL utilizando um banco de dados de uma pizzaria, trabalhando com consultas, índices e views para organizar e apresentar informações.

## Arquivos do projeto

- **README.md:** Documentação do projeto.
- **script.sql:** Criação e estruturação do banco de dados e suas tabelas.
- **queries.sql:** Consultas SQL para buscar e analisar informações.
- **index.sql:** Criação de índices para otimizar as consultas.
- **views.sql:** Criação de views para gerar relatórios.

## Tecnologias utilizadas

- MySQL
- MySQL Workbench
- SQL
